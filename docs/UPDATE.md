# Ενημέρωση στην έκδοση 1.1.0

1. Στην εφαρμογή που έχεις ανοιχτή, πάτησε **Save session** και κράτησε το JSON.
2. Από το ιδιωτικό GitHub release **v1.1.0**, κατέβασε `Planet_X_Observatory_v1.1.0.zip` και αποσυμπίεσέ το. Κράτησε τον νέο φάκελο `Planet-X-SPHEREx-1.1.0` ξεχωριστά από τον παλιό.
3. Στο Terminal που τρέχει την παλιά εφαρμογή πάτησε **Ctrl+C**.
4. Αν ο νέος φάκελος βρίσκεται στα Downloads, τρέξε:

```bash
cd ~/Downloads/Planet-X-SPHEREx-1.1.0
bash scripts/setup.sh && bash scripts/run.sh
```

5. Ανανέωσε το http://127.0.0.1:8501 και έλεγξε ότι το κάτω μέρος γράφει **1.1.0**.
6. Πάτησε **Open saved session** και διάλεξε το JSON που κράτησες. Οι εικόνες και οι σημειωμένες θέσεις σου θα ανοίξουν χωρίς νέα λήψη και η κίνηση θα υπολογιστεί ξανά.

Στο **Your source** εμφανίζονται η μετατόπιση, ο ρυθμός και η αξιολόγηση της κίνησης, με χειροκίνητη ή αυτόματη επιλογή. Το **Sources to inspect** περιλαμβάνει και τη δική σου πηγή. Οι ενδείξεις **Position change measured**, **Motion measured**, **No resolved motion** και **Measurement needs review** ξεχωρίζουν όσα μετρήθηκαν από όσα ακόμη χρειάζονται έλεγχο. Από το Positions & measurement μπορείς να αφαιρέσεις μία μεμονωμένη θέση με το ×. Η πιθανή ταυτοποίηση βρίσκεται στην ίδια καρτέλα με το **Check identity**.

Το παλιό tag v1.0.0 διατηρείται. Το ZIP της νέας έκδοσης δεν περιέχει την προσωπική σου συνεδρία· αυτή βρίσκεται στο JSON που αποθήκευσες.
