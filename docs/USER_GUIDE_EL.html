Πρακτικός οδηγός

PLANET X OBSERVATORY · ΤΕΛΙΚΗ ΕΚΔΟΣΗ 1.1.0

Η εφαρμογή έχει έναν σκοπό: επιλέγεις περιοχή και χρόνο, συγκρίνεις πραγματικές υπέρυθρες παρατηρήσεις και ελέγχεις πιθανή κινούμενη πηγή. Το περιβάλλον της εφαρμογής είναι στα αγγλικά.

Άνοιγμα σε Mac

1. Πάρε ολόκληρο το ιδιωτικό repository από το tag v1.1.0 στο GitHub: Code → Download ZIP. Αποσυμπίεσέ το. Κράτησε μόνο έναν φάκελο για αυτή την έκδοση.

2. Εγκατάστησε Node.js 24.22.1 από το nodejs.org. Άνοιξε νέο Terminal. Η εντολή node --version πρέπει να γράφει v24.22.1 για ίδιο περιβάλλον.

3. Γράψε cd και ένα κενό, σύρε τον φάκελο του project μέσα στο Terminal και πάτησε Enter. Με ls πρέπει να βλέπεις package.json, web, data, scripts.

bash scripts/setup.sh
bash scripts/run.sh

4. Άνοιξε http://127.0.0.1:8501 στον browser. Άφησε το Terminal ανοιχτό. Σταματάς με Ctrl+C. Την επόμενη φορά αρκεί bash scripts/run.sh από τον ίδιο φάκελο.

Τι ελέγχει το setup

Ελέγχει τα αρχεία της έκδοσης, ξαναφτιάχνει τέσσερις αποθηκευμένες συνεδρίες από τα αρχικά FITS, συγκρίνει τα αποτελέσματα και τρέχει τα Node tests. Πρέπει να τελειώσει με Planet X 1.1.0 verified. Η αναφορά γράφεται στο outputs/reproduced/verification.json.

Δεν χρειάζονται npm packages, Python ή API key για την ιστοσελίδα. Το setup λειτουργεί χωρίς internet αφού υπάρχουν ο Node και ολόκληρος ο φάκελος. Το REPRODUCE.md περιέχει την πλήρη διαδικασία από την αρχή.

1 / Επίλεξε ουρανό και χρόνο

WHERE AND WHEN → FIND OBSERVATIONS

Διάλεξε περιοχή

Choose on sky: σύρε τον χάρτη, κάνε zoom, επίλεξε σημείο και πάτησε Use this field. Ο χάρτης δείχνει αστέρες και αστερισμούς αναφοράς J2000· δεν είναι φωτογραφία της ημερομηνίας που διάλεξες.

Εναλλακτικά γράψε M31, Pleiades ή άλλο όνομα και πάτησε το βελάκι. Για ακριβές σημείο άνοιξε Coordinates & filters και βάλε RA / Dec σε μοίρες. Η αναζήτηση ονόματος δίνει σταθερή θέση πεδίου, δεν ακολουθεί αυτόματα την τροχιά ενός αστεροειδή.

Διάλεξε παρατηρήσεις και ημερομηνίες

Observations: NEOWISE ή WISE + NEOWISE για W1/W2. SPHEREx QR2 / QR3 Wide / Deep για τις αντίστοιχες δημόσιες συλλογές. From / To: η αρχική και τελική ημερομηνία σε UTC. Μετά πάτησε Find observations.

Η εφαρμογή αναζητά τα διαθέσιμα αρχεία για τα φίλτρα σου. Δεν υπάρχουν εικόνες για κάθε σημείο σε κάθε μέρα. Οι αποστολές έχουν συγκεκριμένες περιόδους, τροχιές και κάλυψη. Αν δεν επιστραφούν παρατηρήσεις, άλλαξε διάστημα, περιοχή ή συλλογή.

Δες τις εικόνες

Play εναλλάσσει τις εικόνες με κοινή κλίμακα φωτεινότητας. Τα βελάκια, το timeline και οι μικρογραφίες επιλέγουν συγκεκριμένη εικόνα. Zoom μεγαλώνει την εικόνα· όταν έχεις μεγεθύνει, σύρε για μετακίνηση. Reset view επαναφέρει την προβολή.

Η λίστα Observation list κρατά όλες τις γραμμές που επέστρεψαν οι επιτυχημένες αναζητήσεις. Φορτώνονται έως 12 εικόνες κάθε φορά. Earlier / Later images συνεχίζουν στη λίστα. Μπορείς να επιλέξεις έως 12 γραμμές και Load selected, ή Jump to date.

Οι αποτυχίες αναζήτησης και λήψης εμφανίζονται. Μια incomplete λίστα δεν θεωρείται πλήρης. Download full observation list αποθηκεύει τα metadata, όχι όλα τα πρωτογενή FITS.

2 / Βρες και έλεγξε μια πηγή

COMPARE → SELECT → CHECK IDENTITY → SAVE

Επίλεξε αυτό που φαίνεται να κινείται

Πάτησε επάνω στην πηγή μιας εικόνας και μετά στο ίδιο αντικείμενο σε επόμενες εικόνες. Κάθε εικόνα κρατά ένα σημάδι. Κοντά σε μετρημένη κορυφή η επιλογή προσαρμόζεται στο κέντρο της· διαφορετικά εμφανίζεται ως manual. Clear καθαρίζει όλα τα σημάδια. Στο Positions & measurement το × αφαιρεί μία συγκεκριμένη θέση.

Το Your source δείχνει το αποτέλεσμα είτε σημειώσεις εσύ την πηγή είτε επιλέξεις Source 1 από το Sources to inspect: μετρημένη μετατόπιση, ρυθμό, χρονικό διάστημα και αξιολόγηση της κίνησης. Η πηγή σου παραμένει στη λίστα ακόμη κι όταν δεν υπάρχει αυτόματη πρόταση.

Motion measured: η μετατόπιση περνά τους ελέγχους ανεξάρτητων χρόνων, συμβατών εικόνων και σταθερών πηγών αναφοράς. Με δύο μόνο χρόνους εμφανίζεται Position change measured. No resolved motion σημαίνει ότι η αλλαγή δεν ξεχωρίζει από την ανάλυση της μέτρησης. Needs review ζητά έλεγχο των σημείων ή των εικόνων.

Ταυτοποίηση

Check identity συγκρίνει τις συντεταγμένες με πιθανά γνωστά σώματα του Ηλιακού Συστήματος. Χρησιμοποιεί προεπιλογή IMCCE SkyBoT και έλεγχο NASA/JPL Horizons στον χρόνο λήψης από τη θέση WISE ή SPHEREx. Possible match είναι πιθανή ταύτιση που χρειάζεται έλεγχο, όχι ανακάλυψη. Το «κανένα αποτέλεσμα» επίσης δεν αποδεικνύει νέο αντικείμενο.

Αποθηκευμένες πραγματικές παρατηρήσεις

Άνοιξε Saved observations → NEOWISE · 128 Nemesis. Πάτησε Play, Source 1 και Check identity. Οι έξι πραγματικές εικόνες, οι τρεις έγκυρες μετρημένες θέσεις και ο διατηρημένος έλεγχος JPL λειτουργούν offline. Η ένδειξη Saved NASA/JPL check δηλώνει ότι δεν έγινε νέα ζωντανή κλήση.

Το NEOWISE · consecutive images περιέχει 9 πραγματικές εικόνες και 4 έγκυρες αυτόματες θέσεις· δεν απαιτείται ανίχνευση στην τελευταία εικόνα. Το SPHEREx · M31 ανοίγει δύο εικόνες σταθερού γαλαξία με διαφορετικά μήκη κύματος, για επιθεώρηση.

Κράτησε τη δουλειά σου

Save session κατεβάζει ένα JSON με τις φορτωμένες εικόνες, τις επιλογές και το αποτέλεσμα ταυτοποίησης. Open saved session το ανοίγει ξανά χωρίς λήψη αυτών των εικόνων. Το υπόλοιπο observation list περιέχει metadata· για άλλες εικόνες χρειάζεται internet. Image sources ανοίγει τους διαθέσιμους συνδέσμους των αρχικών FITS.

3 / Όταν κάτι δεν λειτουργεί

ΣΥΝΤΟΜΗ ΑΝΤΙΜΕΤΩΠΙΣΗ ΚΑΙ ΟΡΙΑ

No such file or directory

Το Terminal είναι σε λάθος φάκελο. Γράψε cd με κενό, σύρε τον φάκελο της έκδοσης και πάτησε Enter. Τρέξε ls και βεβαιώσου ότι υπάρχει scripts. Μετά ξανατρέξε bash scripts/setup.sh.

Node.js is required / command not found

Εγκατάστησε τον επίσημο Node.js 24.22.1 και άνοιξε νέο Terminal. Έλεγξε node --version. Η ενεργή conda environment δεν αρκεί από μόνη της για να εγκαταστήσει τον Node.

Η σελίδα δεν ανοίγει / port already in use

Κράτησε ανοιχτό το Terminal που τρέχει bash scripts/run.sh. Αν υπάρχει παλιό app στην ίδια θύρα, σταμάτησέ το με Ctrl+C στο δικό του Terminal και ξεκίνα την τελική έκδοση. Ανανέωσε τη σελίδα του browser.

Σφάλμα NASA, αργή λήψη ή άδειο αποτέλεσμα

Έλεγξε internet και ημερομηνίες/συλλογή. Περίμενε και επανάλαβε μία αναζήτηση ή διάλεξε άλλο διαθέσιμο πεδίο. Οι αποθηκευμένες παρατηρήσεις παραμένουν διαθέσιμες. Δεν αντικαθιστούμε μια αποτυχημένη πραγματική λήψη με τεχνητή εικόνα.

Δεν υπάρχει αυτόματη πρόταση

Κενά pixels μπορεί να είναι masked ή εκτός κάλυψης. Δοκίμασε κατάλληλη ομάδα πραγματικών εικόνων με ίδιο band/detector. Η χαμηλή φωτεινότητα, ο κορεσμός, οι συγχωνευμένες πηγές και η διαφορετική PSF δυσκολεύουν τη μέτρηση. Σημείωσε την πηγή στις εικόνες για χειροκίνητη αξιολόγηση. Η απουσία αυτόματης πρότασης δεν ακυρώνει αυτή τη μέτρηση.

Τι σημαίνει «τελική έκδοση»

Το v1.1.0 ορίζει τον ίδιο κώδικα, τα ίδια αρχικά δεδομένα, τις κλειδωμένες εξαρτήσεις και τους ελέγχους αναπαραγωγής. Οι νέες NASA/JPL υπηρεσίες και οι κανόνες ενός μελλοντικού διαγωνισμού μπορούν να αλλάξουν. Η εφαρμογή υποστηρίζει τις δηλωμένες συλλογές WISE/NEOWISE και SPHEREx· δεν περιέχει όλες τις αποστολές της NASA ή συνεχείς παρατηρήσεις όλου του ουρανού.

Πριν φύγεις, κράτησε ολόκληρο τον φάκελο v1.1.0 και τις δικές σου αποθηκευμένες συνεδρίες σε δεύτερο μέσο. Μην αποθηκεύεις κωδικούς ή tokens μέσα στο repository.
